# Phase 2: Brand and visual system

Status: Preparation. Existing Maxbet logo is required before brand colours and artwork are finalized.

The owner confirmed on 30 September 2026 that Maxbet has an existing logo and no tagline. Preserve the existing identity; do not introduce a tagline or substitute an invented logo. The owner will supply the logo in the project chat.

## Approved constraints

- One evolving monorepo and one shared visual system for customer and staff experiences.
- Customer screens prioritize phones; staff screens prioritize desktop workflows.
- Public browsing must not expose wholesale prices, live availability or purchasing controls for unapproved accounts.
- Ghana-first presentation: GHS currency, Africa/Accra dates, clear labels and readable type.
- Brand preview pages contain no operational data or fake system-health claims.

## Implementation sequence

1. Inspect the supplied logo and preserve its proportions and colours. Define accessible text and interaction colours from that identity.
2. Establish typography, spacing, responsive containers, focus states and reduced-motion behaviour.
3. Create reusable navigation, buttons, form fields, cards and status components.
4. Apply the system to public page shells and a clearly identified component preview. Account workflows remain in their dedicated phase.
5. Verify mobile and desktop layouts, keyboard use, contrast and production build; present the visual direction for review.

No brand direction has been approved yet. No database schema is required for this phase.
